# Деплой на Timeweb через GitHub

## Что заливать

Заливайте содержимое папки **`dist/`** — это готовая сборка сайта со всеми
статическими файлами (HTML, CSS, JS). Файлы внутри `dist/` уже оптимизированы
и готовы к раздаче любым статическим хостингом.

## Шаги

1. **Соберите проект** (если собираете локально):
   ```
   npm run build
   ```
   После сборки появится папка `dist/`.

2. **Залейте `dist/` на GitHub**:
   - Создайте репозиторий на GitHub.
   - Скопируйте всё содержимое папки `dist/` (включая `index.html`,
     `404.html` и папку `assets/`) в корень репозитория.
   - Сделайте commit и push.

3. **Настройте Timeweb**:
   - В панели Timeweb создайте статический сайт или привяжите
     GitHub-репозиторий.
   - Укажите корневую папку — корень репозитория (там, где лежит
     `index.html`).
   - Сайт начнёт раздаваться автоматически.

## Важно

- В папке `dist/` есть файл `404.html` — он обеспечивает работу
  внутренних страниц сайта (например `/admin/prices`) на статическом
  хостинге. Не удаляйте его.
- База данных (цены, товары) хранится в Supabase и работает независимо
  от хостинга. Никакой настройки на стороне Timeweb не требуется.
- Файл `.env` не нужен на хостинге — переменные Supabase уже встроены
  в сборку при билде.
